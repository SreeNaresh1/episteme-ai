# Episteme AI — Autonomous Learning Path Engine & Paywall Verifier

[![GitHub Repo](https://img.shields.io/badge/GitHub-SreeNaresh1%2Fepisteme--ai-181717?logo=github&style=flat)](https://github.com/SreeNaresh1/episteme-ai)
[![npm](https://img.shields.io/npm/v/episteme-check.svg?style=flat)](https://www.npmjs.com/package/episteme-check)
[![Live Web App](https://img.shields.io/badge/Live%20App-Vercel-059669?logo=vercel&style=flat)](https://episteme-ai-one.vercel.app)

Turn career goals into strictly time-bounded weekly roadmaps built **100% from verified free public courseware**. Includes live DOM-level paywall detection to prevent bait-and-switch "free trials" requiring credit cards.

### Features
- **Strict Hours Budgeting**: Every curriculum matches your exact hours/week and target duration.
- **Paywall & 404 Verifier**: Scans Schema.org `isAccessibleForFree` metadata and paywall markers.
- **Free Courseware Allowlist**: CS50, MIT OCW, freeCodeCamp, MDN Web Docs, Python Docs, Kaggle, OpenStax.
